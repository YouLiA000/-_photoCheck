## 5. C 接口文档中的两处修正

1. face Detection 的 subtype 是 `face_region`，不是 `face`。
2. `full_file_recheck` 是 `ProcessingResult` 的独立字段，不在 v4 `VerificationReport` 内部；保持这样可避免改变已冻结的 v4 Schema。

另外，规则类 Detection 的 `detector_score` 可以保存 OCR 置信度，并非必须为 null；
规则体本身不提供概率，但不能把上游 OCR score 强行抹掉。
