## 2. 身份证出生日期

文件：

```text
core/detect/entities.py
tests/test_entities.py
badcases/idcard__rule_miss/BC-0010-invalid-birth-date-serial.md
```

规则：

- 校验位通过，但第 7–14 位不是合法日期 → 不报身份证；
- 校验位失败 → 仍报 `idcard_check=fail`、risk 2；
- 不合法候选的字符范围仍要保留，防止手机号规则从同一长数字串中切出假号码。

关键测试：

```text
test_invalid_birth_date_with_valid_checksum_is_not_an_idcard
test_invalid_birth_date_with_bad_checksum_is_still_reported
```

## 4. 契约修复

以下两项已经进入当前 A v2 权威契约，仍需确保 A 主分支不会回退：

```text
_IDCARD_MASK = r"^\d{4}\*{10}(?:\d{4}|\d{3}X)$"
_UNSAFE_RAW_DIGITS = r"\d{7,}"
```

- 身份证末位 X 合法，小写 x 归一为大写；
- meta 日期在原始串上检查长数字串，不先删除分隔符。
